

# My Dotfiles

Personal Linux configuration files.

## Configurations

- **nvim/** - Neovim configuration using LazyVim
- **hypr/** - Hyprland configuration 
- **waybar/** - Waybar configuration (planned)
- **kitty/** - Kitty terminal configuration (planned)

## Installation

Clone the repository:

```bash
git clone https://github.com/Aascharyax/Dot-Files.git ~/dotfiles
```

Create Neovim symlink:

```bash
ln -s ~/dotfiles/nvim ~/.config/nvim
```
